怎麼開始用

iPhone · iPad

  1. 安裝之後打開「設定」→「一般」→「鍵盤」→「鍵盤」
  2. 「加入新的鍵盤…」→ 選青菜台語
  3. 回到清單,點一下青菜台語,打開取用(理由見下一節)
  4. 在任何可以打字的地方,按左下角的 🌐 切到青菜台語

Android

  1. 「設定」→「系統」→「語言與輸入設定」→「螢幕鍵盤」→「管理鍵盤」
  2. 打開青菜台語
  3. 開始打字時,按鍵盤右下角的切換鍵選青菜台語

macOS

  1. 系統設定 → 鍵盤 →「輸入來源」右邊按「編輯…」
  2. 左欄選「繁體中文」→ 勾「青菜台語」

⚠ 找不到多半是找錯分類:它跟系統的注音一樣掛在繁體中文底下, 不是掛在「台語」底下。

裝好了卻切不過去? 登出再登入一次(或重新開機),不用重裝。 症狀是:輸入來源清單裡看得到「青菜台語」,切過去打出來卻是一般注音 —— macOS 把輸入法的身分記在快取裡,而它在新裝或改版之後不一定會跟著更新, 登出會讓系統重新讀一次。登出之後還是一樣,那就是真的壞了,請回報。

Windows

  1. 執行安裝程式(需要系統管理員權限 —— 輸入法要註冊給整個系統用)
  2. 按 Win + 空白鍵 切到青菜台語
  3. 有問題須重新登入或重開機再使用

⚠ 下載時 Windows 會擋一次。瀏覽器可能說「不常下載」、 按下去之後系統會跳一個藍色的「Windows 已保護您的電腦」—— 按「其他資訊」→「仍要執行」。 那是因為我們還沒有程式碼簽章憑證(一年要幾百美金), 不是因為檔案有問題;所有小專案的安裝程式都會遇到。

選字:Ctrl+1～9 挑第幾個,小鍵盤 1～9 也可以; 方向鍵移動,PgUp PgDn 翻頁。

⚠ 數字鍵本身不能拿來選字:大千布局裡 1～9 是 ㄅㄉˇˋㄓˊ˙ㄚㄞ, 佔走了就有九個注音打不出來。這些鍵也只在組字中才被接走 —— 沒在打字的時候 Ctrl+1 還是你原本 app 的快捷鍵。

⚠ 有些從市集裝的程式(例如市集版的記事本)是在更嚴格的沙箱裡跑的。 如果某一個程式裡打不出字、別的程式又正常,那多半是這個原因, 回報時請告訴我們是哪一個程式。

iPhone 為什麼要「完整取用權限」

因為設定頁和鍵盤是兩個程式。你在設定頁調的東西要傳得到鍵盤那邊, 以及回報功能要把打字狀態複製到剪貼簿 —— 這兩件事在 iOS 上都需要那個權限。

打開它的時候 iOS 會跳一段很嚇人的警告,那段話是對所有自訂鍵盤說的, 不是針對這一個。就這個輸入法而言:

  • 它完全沒有網路功能 —— 程式裡沒有任何連線的函式庫,所以就算想送也送不出去
  • 你打的字不記錄、不上傳、不分析
  • 存在你裝置上的資料不會傳送出去

細節見隱私權政策。

打不出某個詞

先試這個為什麼
一聲要按空白鍵 空白鍵就是第一聲。不按的話兩個音節會黏在一起,整串切不開 —— 這是最常見的一種「怎麼都打不到」
往後多按幾格 詞收進來了但排得比較後面。選過一次之後它就會往前排
設定裡把字庫那幾個開關打開 有些詞表預設沒開
加進你自己的菜單 人名、綽號、只有你會打的詞 —— 設定頁的「菜單」可以自己加,不用等我們

上面都試過還是打不到,那就是我們漏收了 —— 請回報,下面說怎麼做。

怎麼回報

回報會把當下的打字狀態複製起來,你再貼進表單就好 —— 不用自己打一次:

平台怎麼做
Windows打到打不出來的那一刻,按 Ctrl + F12
macOS輸入法選單的「回報問題…」
Android · iPhone符號層(?123)的青菜那顆鍵

然後打開回報表單貼上、送出。 表單不問名字、不問 email,我們收到的就只有你貼進去的那幾格。

⚠ 如果不是「打不出某個詞」而是別的問題(當掉、畫面怪怪的、某個程式裡打不了字), 直接寄信給我們,講清楚是哪一個平台、哪一個程式。

Support

Vegetable Taigi · Last updated 2026-10-27

If a word won't come up, try the list below; if it still won't, send a report — we read every one.

Getting started

iPhone · iPad

  1. Settings → General → Keyboard → Keyboards
  2. Add New Keyboard… → 青菜台語 (Vegetable Taigi)
  3. Tap it in the list and turn on Allow Full Access (why: see below)
  4. Tap 🌐 in any text field to switch to it

Android

  1. Settings → System → Languages & input → On-screen keyboard → Manage keyboards
  2. Turn on 青菜台語 (Vegetable Taigi)
  3. Use the keyboard-switch key at the bottom right to select it

macOS

  1. System Settings → Keyboard → click “Edit…” next to “Input Sources”
  2. Choose “Chinese, Traditional” in the left column → tick 青菜台語 (Vegetable Taigi)

Can't find it? It is almost always the wrong category: like the system Zhuyin, it is listed under Chinese, Traditional, not under “Taiwanese”.

Installed but can't switch to it? Sign out and back in (or restart) — no need to reinstall. The symptom: 青菜台語 shows up in the input source list, but typing with it gives ordinary Zhuyin. macOS caches each input method's identity and does not always refresh it after an install or update; signing out makes it read them again. If it still happens after signing out, it really is broken — please report it.

Windows

  1. Run the installer (administrator rights required — an IME is registered system-wide)
  2. Press Win + Space to switch to it
  3. If it doesn't work, sign out and back in, or restart, then try again

Note: some Store-distributed apps run in a stricter sandbox. If typing fails in one app but works everywhere else, that is usually why — please tell us which app.

Why iPhone needs Full Access

The settings screen and the keyboard are two separate processes. Full Access is what lets your settings reach the keyboard, and what lets the report feature copy the current typing state to the clipboard.

iOS shows a strongly worded warning when you enable it. That warning is written for all custom keyboards, not this one. For this keyboard specifically:

  • It has no networking code at all — it could not send anything anywhere
  • What you type is never logged, uploaded, or analysed
  • Anything stored on your device is never sent anywhere

See the Privacy Policy for details.

A word won't come up

Try this firstWhy
Press space for the first tone Space is tone 1. Without it, two syllables run together and the whole string cannot be split — this is the most common cause of "it never comes up"
Page further down the candidate list The word is there, just ranked lower. Pick it once and it moves up
Turn on the extra word lists in Settings Some lists are off by default
Add it to your own menu Names, nicknames, words only you type — add them yourself in Settings → Menus, no need to wait for us

If none of that works, we are missing the word. Please report it.

Sending a report

Reporting copies the current typing state so you can paste it into the form:

PlatformHow

Then open the report form, paste, and submit. The form does not ask for your name or email.

For anything other than a missing word (a crash, a display problem, an app where typing does not work), email us instead and say which platform and which app.
