## 為什麼單獨一個 repo

App Store 與 Google Play 都要求隱私權政策是**公開可讀的網址**,
而輸入法的原始碼庫是私有的。這裡只放那一頁,其餘什麼都沒有。

政策本文與官網上的那一份是同一份(`web/privacy.html`)。
